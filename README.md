# 🏺 Kumbara-Kala (Traditional Pottery Digital Branding)

**Kumbara-Kala** is a "Legacy Branding" Android application designed to help traditional artisans, specifically potters, compete in the modern market. The app allows makers to generate and share "Digital Story Cards" that highlight the health and eco-friendly benefits of using clay products.

## 🚀 Live Demo & APK
You can view the project landing page and download the APK here:
[Live Project URL](https://madhubm2812.github.io/KumbaraKala/)

## ✨ Key Features
- **Artistic Catalog**: A visual gallery of traditional clay items like pots, lamps, and utensils.
- **AI-Powered Story Generator**: Generates marketing content focused on health benefits (e.g., pH balance, natural cooling).
- **Meet the Maker**: Personalized profiles allowing artisans to share their heritage and contact details.
- **WhatsApp Marketing**: Direct sharing of generated "Benefit Cards" to customers via WhatsApp.

## 🛠️ Technical Implementation
- **UI/UX**: Built using **Jetpack Compose** with a traditional, earthy theme.
- **Graphics**: Uses **Android Canvas API** to dynamically overlay text and artisan data onto product images.
- **Sharing**: Integrated **FileProvider** for secure image sharing via Android Intents.
- **Architecture**: Modern Android development practices using Kotlin.

## 📸 How it Works
1. Select a clay item from the gallery.
2. Enter the artisan's name, phone, and heritage story.
3. Generate a high-quality "Digital Story Card."
4. Share the card directly with customers via WhatsApp to drive sales.
